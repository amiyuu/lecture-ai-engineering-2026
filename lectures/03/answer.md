# 第3回 解答

## 演習

- 比較した質問：`AIE2026の講座の宿題にある「3レベル」とは何ですか？`（`gemini-3.5-flash-lite`）
- 第1回（素のLLM）とエージェントの回答の違い：素のLLMは一般的な難易度の3段階を推測し、「可能性が高い」と説明した。エージェントは用語集を検索し、「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」の3段階で、どれか1つに取り組めば完了と回答した。
- `--trace` で見えたツール呼び出し（ツール名と引数）：比較質問では `search_glossary({'query': '3レベル'})` が1回。確認問題の質問「第2回の内容から確認問題を1問出して」では `make_quiz({'lecture': 2})` が1回呼ばれ、「エポック」の問題が返った。
- 1つの質問での LLM 呼び出し回数（`requests`）：比較質問は2回（検索前と検索結果を受けた回答）。確認問題も2回。
- 追加したツールと、docstring に書いた説明：`make_quiz(lecture: int)` を追加。指定した回の用語から1つ選び、「確認問題を出して」のような依頼に問題と答えをJSON形式で返すツール、と説明した。
